# E-Commerce Sales Analysis using SQL

## Project Overview

Analyzed e-commerce sales transaction data using SQL to identify sales trends, product performance, customer behavior, and revenue patterns.

This portfolio project demonstrates practical SQL skills by transforming transactional data into meaningful business insights.

## Objectives

- Analyze overall sales performance
- Identify top-performing products and categories
- Understand customer purchasing behavior
- Analyze monthly revenue trends
- Compare payment methods
- Identify high-value customers
- Calculate cancellation rates and other business KPIs

## Dataset

The project uses a synthetic e-commerce dataset created for portfolio and learning purposes.

The dataset contains:

- Customer information
- Product information
- Order transactions
- Product quantities and prices
- Discounts
- Payment methods
- Order status

### Files

- `customers.csv` – Customer details
- `products.csv` – Product catalog
- `orders.csv` – E-commerce order transactions
- `ecommerce_sales_analysis.sql` – SQL database setup and analysis queries

## SQL Skills Demonstrated

- SELECT and filtering
- Aggregate functions (`COUNT`, `SUM`, `AVG`)
- `GROUP BY` and `HAVING`
- `INNER JOIN`
- Subqueries
- Common Table Expressions (CTEs)
- `CASE` expressions
- Date-based analysis
- Sorting and limiting results
- Window functions
- `DENSE_RANK()`
- Cumulative revenue analysis

## Analysis Performed

### 1. Sales Performance
Calculated total orders, total revenue, and average order value.

### 2. Product Analysis
Identified the highest-performing products based on units sold and revenue.

### 3. Category Analysis
Compared revenue generated by different product categories.

### 4. Customer Analysis
Identified customers with multiple purchases and analyzed their contribution to overall revenue.

### 5. Monthly Sales Trends
Analyzed revenue month-by-month to understand sales patterns.

### 6. Payment Analysis
Compared order volume and revenue across different payment methods.

### 7. Advanced SQL Analysis
Used CTEs and window functions to rank products within categories and calculate cumulative revenue.

### 8. Order Status Analysis
Calculated the percentage of cancelled orders to understand order performance.
