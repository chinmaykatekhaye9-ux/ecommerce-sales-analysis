# Business Insights from E-Commerce Sales Data

## Project Overview
Analyzed over 10,000 e-commerce sales records to uncover customer behavior, product performance, and revenue trends.

## Objectives
- Understand sales performance
- Identify top-performing products
- Analyze customer purchasing behavior
- Generate actionable business insights

## Tools Used
- Python (Pandas)
- SQL
- Excel
- Power BI

## Approach
1. Cleaned and transformed raw sales data
2. Performed exploratory data analysis using Python
3. Queried data using SQL
4. Identified key business trends and KPIs
5. Built interactive Power BI dashboards

## Key Insights
- Identified top-performing products
- Discovered high-value customer segments
- Analyzed seasonal sales trends
- Highlighted revenue-driving categories

- Data Cleaning
- Data Analysis
- SQL
- Power BI

- Data Visualization
